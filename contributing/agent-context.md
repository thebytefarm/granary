# Agent context

Start a repository task at root `AGENTS.md`. It owns commands and permission boundaries and routes standards retrieval through `.context/INDEX.md`.

Granary declares only `bytefarm/recommended-typescript` in its own dependencies. The installed set contains engineering, Git, documentation, agent instructions, and functional TypeScript. Read the component entrypoints in that order, then the topics needed by the change.

Almanac's standards region indexes installed shared/TypeScript pages. Its contributor/public region indexes repository workflow and product references. Authored Rust and Python material remains in `packs/` for distribution and example verification.

Edit authored component pages, then follow the deliberate refresh procedure in [Contributing](README.md). Installed files and their lock are generated outputs. A normal `install` verifies and restores the recorded resolution.

See [using agent context](../docs/guides/use-agent-context.md) for consumer guidance and [project configuration](../docs/reference/project-config.md) for destination and integrity contracts.
