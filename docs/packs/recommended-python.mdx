# Recommended Python

Use this set for Python projects built around pure transformations, immutable domain values, explicit capabilities, and typed Results. It uses `returns` for failure and composition, with shared rules for engineering decisions and collaboration.

**Pack:** `bytefarm/recommended-python` · **Version:** `0.1.0`

## Install

With the [workspace CLI built](/getting-started/quick-start) and on your PATH, run from a project beside a checkout named `granary-packs`:

```sh
granary add file:../granary-packs/packs#recommended-python --output .granary/context/docs/bytefarm
```

## Use the installed context

Start at `.granary/context/INDEX.md`. Read the shared engineering rules first, then the topics relevant to your change. Python rules apply to Python source and examples. The documented `returns` decorator and composition typing uses its compatible mypy plugin; adding dependencies still follows your project's approval rules.

Adding another recommended language set reuses the shared packs. The lockfile pins the source revision and file integrity; `granary install` restores the same context.
