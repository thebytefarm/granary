# Recommended TypeScript

Use this set for TypeScript projects built around pure functions, immutable values, factories, typed Results, and exhaustive matching. It combines language mechanics with shared rules for engineering, review, documentation, and agent context.

**Pack:** `bytefarm/recommended-typescript` · **Version:** `0.1.0`

## Install

With the [workspace CLI built](/getting-started/quick-start) and on your PATH, run from a project beside a checkout named `granary-packs`:

```sh
granary add file:../granary-packs/packs#recommended-typescript --output .granary/context/docs/bytefarm
```

## Use the installed context

Start at `.granary/context/INDEX.md`. Read the shared engineering rules first, then the topics relevant to your change. TypeScript rules apply to TypeScript source and examples; repository commands and dependency approval come from your project's instructions.

Adding another recommended language set reuses the shared packs. The lockfile pins the source revision and file integrity; `granary install` restores the same context.
