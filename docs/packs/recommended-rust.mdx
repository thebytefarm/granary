# Recommended Rust

Use this set for Rust projects built around pure functions, borrowed inputs, native Result and Option, exhaustive enums, and iterator transformations. It combines ownership-aware language rules with shared engineering and collaboration standards.

**Pack:** `bytefarm/recommended-rust` · **Version:** `0.1.0`

## Install

With the [workspace CLI built](/getting-started/quick-start) and on your PATH, run from a project beside a checkout named `granary-packs`:

```sh
granary add file:../granary-packs/packs#recommended-rust --output .granary/context/docs/bytefarm
```

## Use the installed context

Start at `.granary/context/INDEX.md`. Read the shared engineering rules first, then the topics relevant to your change. Rust rules apply to Rust source and examples; the supported compiler, repository commands, and dependency approval come from your project's instructions.

Adding another recommended language set reuses the shared packs. The lockfile pins the source revision and file integrity; `granary install` restores the same context.
