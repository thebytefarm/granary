## Install

Use the [workspace CLI](/getting-started/quick-start); the current contract is not published yet. From a project beside a checkout named `granary-packs`:

```sh
granary add file:../granary-packs/packs#recommended-typescript --output .granary/context/docs/bytefarm
```

For a polyglot project, select several sets at one destination in `granary.json`:

```json
{
  "name": "polyglot",
  "packs": {
    "file:../granary-packs/packs#recommended-typescript": {
      "output": ".granary/context/docs/bytefarm"
    },
    "file:../granary-packs/packs#recommended-rust": { "output": ".granary/context/docs/bytefarm" },
    "file:../granary-packs/packs#recommended-python": { "output": ".granary/context/docs/bytefarm" }
  }
}
```

Shared components install once. All three sets together install seven unique packs. Language-specific rules apply only to files in that language.

Read `.granary/context/INDEX.md` after installation for the component reading order. Commit `granary.json` and `granary-lock.json`; teammates restore the same material with `granary install`.
