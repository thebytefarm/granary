# Changesets

Run `pnpm changeset` for changes to the published `granary-ai` package. Tooling-only changes do not need a changeset.

Use `pnpm version-packages` to apply pending changesets. Use `pnpm release` to validate, build, and publish a release.

The existing `0.0.1` npm release is a coming-soon placeholder. Bump the package version before the first implementation release.
